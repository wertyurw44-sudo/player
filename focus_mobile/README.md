# Фокус Плеер для Android

Музыкальный плеер с папками, режимом учёбы (учёба / отдых по сеансам),
фото и видео для треков и 8 стилями оформления.

## Как получить APK (бесплатно, без установки программ)

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта).
2. Нажмите «+» вверху справа → **New repository**. Имя любое, например `focus-player`.
   Оставьте **Public** и нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**.
4. Откройте распакованную папку `focus_mobile` и перетащите в окно браузера
   **всё её содержимое** (папки `www`, `.github` и файлы `package.json`,
   `capacitor.config.json`, `README.md`). Нажмите **Commit changes**.
   Папка `.github` скрытая: в Windows включите «Вид → Скрытые элементы», чтобы её увидеть.
   Если папка `.github` не загрузилась (во вкладке Actions пусто): нажмите
   **Add file → Create new file**, в поле имени введите `.github/workflows/build-apk.yml`,
   вставьте содержимое этого файла из архива и нажмите **Commit changes**.
5. Откройте вкладку **Actions**. Сборка «Собрать APK» начнётся сама.
   Подождите 5–8 минут, пока появится зелёная галочка.
6. Нажмите на сборку и внизу, в разделе **Artifacts**, скачайте `FocusPlayer-APK`.
   Это zip-архив, внутри лежит `FocusPlayer.apk`.
7. Перекиньте `FocusPlayer.apk` на телефон и откройте его.
   Android спросит разрешение на установку из неизвестных источников — разрешите.

## Обновление
Замените файл `www/index.html` в репозитории (Add file → Upload files).
Новая сборка запустится автоматически. Установите новый APK поверх старого —
музыка и папки сохранятся.
